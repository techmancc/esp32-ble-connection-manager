🚀 ESP32 BLE Connection Parameter System - Client Setup

UPDATED: Now supports both Access Point mode AND home WiFi connection!

=== QUICK START (Home WiFi Mode - Recommended) ===

1. CONFIGURE ESP32 FOR HOME WIFI:
   .\setup_home_wifi.ps1

   This script will:
   - Find your ESP32 (AP mode or home network)
   - Configure it to connect to your home WiFi
   - Both ESP32 and your PC will be on the same network!

2. START DEVELOPMENT SERVER:
   cd client
   npm install
   npm run dev -- --host

3. OPEN DASHBOARD:
   http://localhost:5173

   The client will automatically discover your ESP32's IP address!

=== ALTERNATIVE: Access Point Mode ===

If you prefer the old method or home WiFi doesn't work:

1. CONNECT TO ESP32 NETWORK:
   - WiFi Network: "ESP32-BLE-Control-XXXXXX" 
   - Password: "esp32ble"
   - Wait for connection (you'll get an IP like 192.168.4.2 or 192.168.4.3)

2. VERIFY CONNECTION:
   .\test_esp32_connectivity.ps1

3. START CLIENT:
   cd client
   npm run dev -- --host

4. ACCESS DASHBOARD:
   http://192.168.4.1/ (ESP32's web interface with React app links)
   OR your React dev server with automatic ESP32 discovery

=== TROUBLESHOOTING ===

Problem: Client can't connect to ESP32
Solution: 
1. Try the WiFi setup script: .\setup_home_wifi.ps1
2. Check ESP32 Serial Monitor (115200 baud) for network status
3. Use ESP32's WiFi config page: http://[ESP32-IP]/wificonfig

Problem: ESP32 not found
Solution:
1. Check ESP32 is powered and programmed
2. Look for "ESP32-BLE-Control-XXXXXX" WiFi network
3. Check your router's connected devices list
4. Try network scan: nmap -sn 192.168.1.0/24

Problem: Parameters not applying
Solution:
1. Check BLE device is connected in Security panel
2. Verify parameter values are within BLE specification ranges  
3. Check ESP32 Serial Monitor for validation messages

=== ESP32 NETWORK STATUS ===

The ESP32 will show network information on Serial Monitor:
- Home WiFi: Shows assigned IP address (192.168.1.x, 10.0.0.x, etc.)
- AP Mode: Shows "Access Point started" with IP 192.168.4.1

Both modes support the full dashboard and API functionality!
